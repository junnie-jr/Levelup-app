# Level UP

Personal lifting and cardio tracker. Web app (GitHub Pages) plus an Android APK built with Capacitor.

- `index.html` is the single source for both the web app and the APK.
- Run **Actions > Build release APK** to publish a signed APK to Releases.
- Needs these repository secrets: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
- Package name: `com.junnie.levelup`.
